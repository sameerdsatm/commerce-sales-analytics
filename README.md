# E-Commerce Sales Performance Analytics

## Project Overview
This project analyzes retail sales data to uncover top-performing product categories and monthly revenue trends using Python.

## Dataset Link
- **Source:** Simulated E-Commerce Dataset (generated via Python/Pandas).

## Technologies Used
- **Python** 
- **Pandas & NumPy** (For data cleaning and math)
- **Matplotlib & Seaborn** (For drawing charts)
- **Jupyter Notebook** (For writing and running the code)
